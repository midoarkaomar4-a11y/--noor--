# تشغيل المنصة بحسابات حقيقية (مجانًا)

الملفات دي بتشتغل في وضعين:
- **تجريبي:** من غير أي إعداد (بيحفظ في المتصفح بس). ده الوضع الحالي.
- **حقيقي:** بعد ما تربطها بـ Supabase (مجاني). حسابات الطلاب والكورسات والفيديوهات بتتشارك لكل الأجهزة.

## 1) أنشئ مشروع Supabase
1. سجّل على supabase.com وأنشئ مشروع جديد (الخطة المجانية Free). احفظ كلمة مرور قاعدة البيانات.
2. من **SQL Editor** اضغط New query، والصق محتوى ملف `schema.sql` كله، واضغط Run.

## 2) اضبط الدخول
من **Authentication ثم Providers ثم Email**: اقفل خيار **Confirm email** (عشان الطالب يدخل بعد التسجيل على طول من غير رسالة).

## 3) انسخ المفاتيح
من **Project Settings ثم API** انسخ:
- Project URL
- anon public key

والصقهم في ملف `config.js`:
```js
window.MM_CONFIG={
  SUPABASE_URL:'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY:'eyJ...'
};
```
المفتاح ده عادي يكون ظاهر في الموقع. الحماية الفعلية من قواعد الصلاحيات اللي في `schema.sql`. لا تحط أبدًا المفتاح الثاني (service_role).

## 4) أنشئ حساب الأدمن
1. من **Authentication ثم Users ثم Add user ثم Create new user**: الإيميل `mido@maged-students.com`، وكلمة مرور قوية من اختيارك، واختار Auto Confirm User.
2. من SQL Editor شغّل:
```sql
insert into public.profiles (id, name, login_email, is_admin)
select id, 'mido', email, true from auth.users where email = 'mido@maged-students.com';
```
بعدها تدخل من صفحة الدخول العادية: الاسم `mido` وكلمة المرور اللي اخترتها.

## 5) احذف ملف التجربة
احذف `demo-auth.js` من الفولدر (فيه كلمة مرور الوضع التجريبي). استخدم كلمة مرور مختلفة تمامًا للأدمن الحقيقي.

## 6) ارفع الموقع
اسحب الفولدر على **app.netlify.com/drop**، أو استخدم GitHub Pages.

## ملاحظات
- الفيديو أو الملف الواحد لحد 50 ميجا في الخطة المجانية. للفيديوهات الأطول استخدم "رابط" (يوتيوب غير مدرج).
- المساحة المجانية 1 جيجا للملفات. ولو المشروع مفيهوش نشاط أسبوع، Supabase بيوقفه مؤقتًا وتشغّله من لوحتهم بضغطة.
- الطلاب بيسجلوا حساباتهم بنفسهم. تقدر تشوفهم وتحذفهم من صفحة الإدارة.
- الدخول بالاسم وكلمة المرور: لو اتنين طلاب بنفس الاسم وكلمة المرور هيتلخبطوا، فوجّه الطلاب لكلمات مرور مميزة.
